One platform for cost, security and observability.

Six subsystems, each shipped in the repo with code, schema and tests.

Telemetry ingestion

Celery collectors pull CloudWatch, Cloud Monitoring and the Kubernetes Metrics API into a TimescaleDB hypertable with compression and 90-day retention.

CNN anomaly detection

Every 15 minutes, 24 hours of eight metrics become an 8×96 heatmap. A PyTorch CNN labels it normal, cost spike, idle or intrusion and opens an alert above 0.8 confidence.

Agent swarm

A LangGraph graph runs a FinOps optimizer and a Security auditor in parallel, then a Remediation Planner writes the Terraform and stops at an approval gate.

Agentic RAG

Qdrant indexes CIS benchmarks, runbooks and Terraform state. Agents cite the control or runbook behind each recommendation.

Dual-engine LLM gateway

Groq Llama-3.3-70b handles fast tool calls and chat. Gemini handles deep reasoning and long context. Circuit breakers, timeouts, token and cost tracking, and a Redis semantic cache sit in front.

Governed remediation and MCP

Fernet-encrypted vault, JWT roles, a hash-chained audit log the database refuses to edit, and blast-radius limits. The MCP server exposes read and propose tools only. It cannot approve or apply.

Security is part of the design, not a layer on top.

Eleven controls from the repo’s STRIDE model, each with code behind it.

LLM firewall

Regex screening blocks override and exfiltration attempts, and secrets or personal data are redacted before any model sees them. Try pasting a key into the assistant.

Indirect injection defense

Tool and retrieval output is scrubbed and fenced as untrusted data before it re-enters a prompt.

Human-in-the-loop gate

Agents propose. People approve. Four-eyes rule, and admin sign-off for high blast radius or any policy violation.

Policy-as-code critic

Open SSH or RDP, wildcard IAM, public buckets and disabled encryption are rejected, with one self-correction pass.

Identity

JWT roles, scrypt password hashing and TOTP multi-factor authentication built to RFC 6238.

Secrets and audit

Fernet-encrypted credential vault and a SHA-256 hash-chained audit log that the database refuses to update or delete.

Containers and edge

Non-root containers with dropped capabilities, an nginx edge with rate limits and security headers, internal-only metrics, Kubernetes network policies.

Supply chain

CodeQL, Trivy, gitleaks and Dependabot run in CI. The API reports Prometheus metrics and OpenTelemetry traces.
